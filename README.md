This project is a multi-page web application focused on health and fitness tracking. The main entry point is a dashboard that displays personalized widgets summarizing key health and fitness metrics. Each widget can link to a dedicated detail page offering deeper insights, including filters, date ranges, and historical views. The application integrates with third-party health services such as Google Fit, Pixel Watch, and Fitbit to retrieve activity and biometric data, while all personal and user-specific information is securely stored in an owned database (e.g., SQLite) under full user control.
